# Ansuni Ankahi Bate (अनसुनी अनकही बातें)
A premier romantic Hindi Poetry, Shayari, Kavita, and Love Stories portal with built-in native Android Studio project and GitHub Actions automated APK builder.

## How to run locally:
1. Run `npm install`
2. Run `npm run dev`
3. Open http://localhost:3000

## How to build APK:
1. Upload to GitHub repository
2. Go to Actions -> Build Ansuni Ankahi Bate Android APK -> Run workflow
3. Download debug APK from Artifacts!
